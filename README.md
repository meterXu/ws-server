# 🌾☠️信使
基于koa服务的websocket管理工具，支持：
* 消息上报
* 消息推送
* 定时广播
* 消息日志

可用于模拟ws、mqtt服务，ws开发等环境。

## 一键安装
```bash
docker run -d --name ws-server -p 3000:3000 meterxu/ws-server:latest
```
